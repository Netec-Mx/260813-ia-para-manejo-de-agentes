# IA para Manejo de Agentes

Aprenderás a utilizar, configurar y supervisar agentes inteligentes impulsados por IA generativa para automatizar tareas, interactuar con información empresarial y optimizar procesos cotidianos mediante herramientas modernas no-code y low-code.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

  - Descripción: Explorar diferentes agentes de IA preconstruidos, incluidos los disponibles en herramientas como Microsoft 365 Copilot, y comparar sus comportamientos.
  - Duración estimada: 30 min
